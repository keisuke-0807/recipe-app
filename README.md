# レシピ帳（個人用レシピ管理 PWA）

iPhoneのホーム画面に追加して使う、オフライン対応のレシピ管理アプリです。
データはすべて端末内（IndexedDB）に保存され、外部には送信されません。

## 機能
- レシピの登録・編集・削除（写真・材料・手順・メモ・参考URL・タグ・カテゴリ）
- 検索（料理名・材料・タグ・メモ。ひらがなとカタカナは区別しない）
- カテゴリやお気に入りで絞り込み
- 人数を変えると分量を自動で換算（例：「大さじ1と1/2」×2 → 「大さじ3」）
- 材料・手順の「まとめて入力」（音声入力や貼り付けた文章を、材料名と分量、手順ごとに自動で分ける）
- 調理中に材料・手順をタップしてチェック
- 買い物リスト（レシピの材料を人数に合わせた分量で追加／手入力で追加／チェック・削除）
- 調理モード（画面のスリープを防止。対応端末のみ）
- バックアップの書き出しと読み込み（JSON。写真も含む）

## ファイル構成
| ファイル | 役割 |
|---|---|
| index.html | 画面の骨組み |
| app.js | 画面表示と操作 |
| db.js | データ保存（IndexedDB） |
| style.css | デザイン（ダークモード対応） |
| sw.js | オフライン対応（Service Worker） |
| manifest.webmanifest / icons/ | ホーム画面用の設定とアイコン |

## PCで動かす
```
cd recipe-app
python -m http.server 8000
```
ブラウザで http://localhost:8000 を開きます。

## iPhoneで使う（GitHub Pages）
1. GitHubにリポジトリを作り、このフォルダの中身をアップロードする
2. Settings → Pages で、Branch を `main` / `/ (root)` にして保存する
3. 表示された `https://<ユーザー名>.github.io/<リポジトリ名>/` をiPhoneのSafariで開く
4. 共有ボタン →「ホーム画面に追加」をタップする

公開されるのはアプリのプログラムだけです。レシピのデータはiPhoneの中にだけ保存されます。

## 更新するとき
ファイルを変更したら、`sw.js` の `CACHE` の名前を変えてください（例：`recipe-book-v2`）。
変更はアプリを2回起動すると反映されます。

## 注意
- Safariの「履歴とWebサイトデータを消去」を実行すると、レシピも消えます。ときどき「設定 → バックアップを書き出す」で書き出しておいてください。
- Safariで開いたときと、ホーム画面から開いたときでは、保存場所が別になります。普段はホーム画面から使ってください。
